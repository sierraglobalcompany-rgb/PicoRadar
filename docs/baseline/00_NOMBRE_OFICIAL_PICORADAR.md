# NOMBRE OFICIAL DEL PROYECTO

**Marca:** PicoRadar  
**Título previsto en tiendas:** **PicoRadar: Pico y Placa**

Esta decisión de naming es posterior a la Baseline de Producto v1.0 y **supersede únicamente el nombre genérico “PicoRadar: Pico y Placa”**. No modifica ningún flujo, arquitectura, alcance o decisión funcional.

## Uso de nombre

- Marca corta en UI/logo: `PicoRadar`
- Título de Google Play: `PicoRadar: Pico y Placa`
- Título de App Store: `PicoRadar: Pico y Placa`
- Nombre interno del proyecto/repo: `picoradar`
- Codename técnico aceptable: `picoradar`

## IDs de aplicación propuestos para C00

Se usarán como baseline técnica de trabajo:

- Producción: `co.picoradar.app`
- Staging: `co.picoradar.app.staging`
- Dev: `co.picoradar.app.dev`

Estos IDs deben comprobarse antes del primer alta definitiva en las tiendas. Cambiar el package/application ID después de publicar no es una operación trivial.

## Labels Android/iOS

- Prod: `PicoRadar: Pico y Placa`
- Staging: `PicoRadar Staging`
- Dev: `PicoRadar Dev`

## ASO

Palabras objetivo principales:
- pico y placa
- fotomultas
- radares
- SOAT

La marca no debe convertirse en keyword stuffing. El título ya incorpora `Pico y Placa`; fotomultas/radares/SOAT se trabajarán en subtítulo, descripción y metadata según cada tienda.

## Clearance pendiente

El nombre queda adoptado para desarrollo, pero antes de registro de marca/publicación comercial debe hacerse un clearance final:
- disponibilidad real de `picoradar.com`;
- Google Play;
- App Store;
- SIC Colombia / antecedentes marcarios;
- búsquedas web y clases relacionadas.

Se encontraron usos no relacionados de “Picoradar/PICORadar” en otros sectores, por lo que este control final no debe omitirse.
