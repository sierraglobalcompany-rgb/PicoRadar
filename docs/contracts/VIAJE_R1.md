## Wire contract v1
POST /api/v1/trips/preview only on explicit CTA. JSON request keys ONLY:
requestId (bounded opaque local request token, not vehicle ID), origin and destination ({code, municipality, department}), departureUtc (ISO8601 UTC), timeZone (America/Bogota), vehicleCategory (car/motorcycle/taxi), paymentMethod (cash), alternatives (1..3).
Municipal labels/codes are validated against the existing server geography catalog, then geocoded by the provider. No invented coordinates, no arbitrary client URL. Same municipality without distinct points is validation error. Local snapshot retains VehicleProfile for plate evaluation, NEVER serializes it. Car/moto category describes an ordinary unmodified two-axle vehicle without trailer; unknown physical or taxi mapping remains unsupported pending verification, not silently substituted.

Success body is a TripPlan object with requestId, generatedAtUtc, provider, attribution, origin/destination resolved points ({label, latitude, longitude}), routes (1..3 distinct, sorted duration).
Each route: id, summary, distanceMeters positive integer, durationSeconds positive integer, timeBasis (static/traffic, truthful provider basis), tolls object. ETA always departureUtc + duration, Bogota display independent of device zone. Identity derives from actual route geometry on server; geometry not sent/stored on mobile.
Tolls: coverage (complete/partial/unknown/no_charge_confirmed/unsupported_vehicle), currency COP, totalMinor nullable integer (COP centavos), subtotalMinor nullable integer, paymentMethod, vehicleCategory, charges ordered array, missingRates integer. Charge: name, amountMinor nullable integer, sourceUrl nullable HTTPS, effectiveAt nullable date string. Duplicate station visits are NOT automatically deduplicated. Missing effective dates remain null; generatedAt is not tariff date. No_charge_confirmed needs explicit evidence, empty list alone is unknown. Complete total must equal all applicable charges; partial has subtotal only. Unknown cannot win cheapest comparison.
Failure JSON {error:{code}} with code validation/no_route/unsupported_vehicle/not_configured/quota/timeout/invalid_upstream/network. Never raw provider body, PII, URLs with keys or exception message. HTTP 422/503/429/504/502 as appropriate. No automatic POST retry.
